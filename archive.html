Pulling again重新匯出

The export uses匯出工具是 DiscordChatExporter (CLI 2.47) with a bot that has View Channels and Read Message History on the server. Forum channels have no messages of their own, so threads must be included or most of a forum server goes missing.（CLI 2.47），搭配一個在伺服器上有「檢視頻道」與「讀取訊息歷史」權限的機器人。論壇頻道本身沒有訊息，一定要把討論串一起匯出，否則論壇型伺服器的大部分內容會遺漏。

DISCORD_TOKEN=… dce exportguild -g 1521456968080822402 \
  --include-threads All --include-vc false \
  -f Json -o "json/%c.json" --media --reuse-media --media-dir media

Attachment links in Discord expire, which is why media is downloaded with the text. Then run python3 tools/build.py to rebuild the pages.Discord 的附件連結會過期，所以要連同文字一起下載。完成後執行 python3 tools/build.py 重建頁面。
